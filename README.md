# landing-page
# 🌐 React + TypeScript Landing Page (Frontend Only)

A modern **frontend-only landing page** built with **React 18** and **TypeScript**.
This project focuses purely on **UI, layout, and component structure**, making it ideal for portfolios, interviews, and design showcases.

---

## ✨ Features

* ⚛️ React 18 (Frontend only)
* 🟦 TypeScript for type safety
* 🎨 Custom CSS (no UI frameworks)
* 📄 Single-page landing layout
* 🧩 Reusable component structure
* 🚀 Fast build using Vite

---

## 🛠 Tech Stack

* **Framework:** React.js
* **Language:** TypeScript
* **Styling:** Custom CSS
* **Bundler:** Vite
* **Package Manager:** npm

---
